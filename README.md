
# Management Engineering Python Portfolio

This repository contains Python projects focused on solving industrial engineering, operations management, and supply chain problems.

## Projects Included:
1. **Inventory & Supply Chain Optimization (`inventory_optimizer.py`)**: 
   - Calculates the Economic Order Quantity (EOQ).
   - Simulates daily warehouse inventory levels, demand fluctuations, and automated reorder points using `Pandas` and `NumPy`.
2. **Production Scheduling Optimization (`production_scheduler.py`)**: 
   - Solves a linear programming model to maximize manufacturing profit under resource and machine capacity constraints using `PuLP`.
